📝 To-Do App

A simple task manager built with HTML,CSS,andJavaScript.

🚀 Features

- Add, edit, and delete tasks
- Mark tasks as completed
- Set due date for each task
- Missed tasks highlighted in red automatically
- Filter tasks — All, Active, Done, Today, Overdue
- Data saved in LocalStorage (persists after refresh)

🛠️ Tech Stack

- HTML
- CSS
- JavaScript
